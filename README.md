# Notification-Management-System

A scalable multi-channel Notification Management System built using Java Spring Boot, React, Next.js, MySQL, and Tailwind CSS.

The platform is designed to simulate modern enterprise notification infrastructure capable of handling real-time communication across multiple delivery channels including email, SMS, push, and in-app notifications.

# Overview

This project focuses on designing a robust and extensible notification platform with support for:

- Multi-channel notification delivery
- Real-time notification updates
- Retry and failure handling mechanisms
- User notification preferences
- Scalable backend architecture
- Secure REST APIs
- Responsive frontend dashboard

The system demonstrates backend system design concepts commonly used in enterprise applications.

# Features
- Notification Channels
- Email Notifications
- SMS Notifications
- Push Notifications
- In-App Notifications

# Core Functionalities

- Real-time updates using WebSocket
- Notification status tracking
- Retry mechanism for failed deliveries
- User-specific notification preferences
- Authentication & authorization
- Modular service-based architecture
- Analytics and tracking dashboard

# Tech Stack

Backend - 

Java 21, Spring Boot, Spring Security, Spring Data JPA, MySQL, Maven, WebSocket, Validation API, Lombok

Frontend - 

React, Next.js, Tailwind CSS
